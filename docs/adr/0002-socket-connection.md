# ADR 0002: 소켓으로 TCP 연결 직접 다루기

이 문서를 읽으면 mini-redis 서버와 클라이언트가 소켓 함수를 어떤 순서로 호출해 연결을 맺고 데이터를 주고받는지 알 수 있어요.

- 상태: 채택
- 날짜: 2026-11-13

## 결정

mini-redis 서버는 Python `socket` 모듈로 TCP 연결을 직접 다루고, 그 위에서 [RESP](0001-protocol-resp.md)로 요청과 응답을 주고받아요.

## 소켓이란

소켓을 만들면 운영체제가 파일처럼 다룰 수 있는 번호(파일 디스크립터)를 하나 줘요. 프로그램은 이 번호에 바이트를 쓰고(`send`) 읽기만(`recv`) 하면 돼요. 패킷을 나누거나 유실된 걸 다시 보내는 복잡한 TCP 처리는 운영체제가 해 줘요.

## 서버 흐름

| 단계 | 함수 | 식당에서는 | 실제로는 |
| --- | --- | --- | --- |
| 1 | `socket()` | 안내 데스크를 하나 설치해요 | 운영체제에서 소켓을 받아요 |
| 2 | `bind()` | 데스크에 "6379호" 간판을 달아요 | 소켓을 6379번 포트에 묶어요. 손님이 찾아올 주소가 생겨요 |
| 3 | `listen()` | "영업 시작" 팻말을 걸어요 | 접속을 받을 준비가 됐다고 운영체제에 알려요. 여기까지가 서버 켜기(R-01)예요 |
| 4 | `accept()` | 손님이 오면 전용 테이블로 안내해요 | 클라이언트 전용 연결 소켓을 새로 만들어요. 데스크는 다음 손님을 기다려요 |
| 5 | `recv()` | 테이블에서 주문을 받아요 | 클라이언트가 보낸 바이트를 읽고 파싱해요 |
| 6 | `send()` | 음식을 내줘요 | 응답(`+OK` 등)을 보내요 |
| 7 | `close()` | 손님이 떠나면 테이블을 치워요 | 연결 소켓을 닫아요 |

## 클라이언트 흐름

| 단계 | 함수 | 식당에서는 | 실제로는 |
| --- | --- | --- | --- |
| 1 | `socket()` | 손님이 식당에 갈 준비를 해요 | 소켓을 받아요 |
| 2 | `connect()` | "192.168.0.7 건물 6379호"로 찾아가요 | 서버에 연결해요. 운영체제가 손님 쪽 포트(51234 같은 임시 번호)를 자동으로 붙여 줘요 |
| 3 | `send()` | 주문해요 | `SET name kim`을 RESP로 보내요 |
| 4 | `recv()` | 음식을 받아요 | 응답을 읽고 파싱해요 |
| 5 | `close()` | 식당을 나가요 | 연결을 끊어요 |

## 결과

- 프로그램은 파일 디스크립터에 `send`와 `recv`만 하면 되고, 패킷 분할과 재전송은 운영체제에 맡겨요.
- 서버는 `listen()`까지 마치면 켜진 상태(R-01)가 되고, `accept()`로 클라이언트마다 전용 연결 소켓을 만들어요.
